# SOP-EQ-007 HPLC Qualification, Calibration and Drift Monitoring
Synthetic training document.

## 1. Calibration schedule
HPLC systems are calibrated every 6 months and after any major repair. A system suitability test (SST) is run with every sequence.

## 2. Drift monitoring
Trend the results of the control sample and routine assays per instrument. A sustained shift of the running average beyond three standard deviations (for example an EWMA control chart) is a drift signal. On a drift signal: stop using the instrument for release testing, raise a deviation, perform an unscheduled calibration, and review every result since the shift began.

## 3. Return to service
After recalibration, the instrument returns to service only after the control sample passes on two consecutive days and the calibration record is approved by QA.

## 4. Typical causes of drift
Detector lamp ageing, pump seal wear, column degradation, mobile phase preparation errors, and temperature control faults.
