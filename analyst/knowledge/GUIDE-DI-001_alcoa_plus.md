# GUIDE-DI-001 Data Integrity: ALCOA+ Principles
Synthetic training document.

## 1. The principles
Attributable (who did it and when), Legible, Contemporaneous (recorded at the time), Original (first capture or certified copy), Accurate. Plus: Complete, Consistent, Enduring, Available.

## 2. What this means for analytics data
Missing analyst IDs break Attributable. Completion dates before start dates break Contemporaneous and Accurate. Duplicate records break Original and Consistent. Results with the wrong unit scale break Accurate. Status that disagrees with the result breaks Consistent. Missing results break Complete.

## 3. Reviewing data
Reviewers raise queries against the owning lab. Reviewers never edit original records. Corrections are made by the owner with a reason, a date and a signature, leaving the original visible.
